This is the complete list of libraries and instructions to share EpiSpot with another developer. To ensure it runs on their machine (especially if they want GPU acceleration like your RTX 5060), they need to follow these specific steps.

1. The requirements.txt File
Copy and paste this into a new text file named requirements.txt in your backend folder:

Plaintext
# Web Framework
fastapi[standard]
uvicorn
watchfiles
pydantic

# Machine Learning & AI
torch
transformers
accelerate

# Data Processing & Math
pandas
numpy
scipy
scikit-learn

# Networking
requests
2. Instructions for the recipient (The "README")
If you send this code to someone, give them these exact steps to get started:

Step 1: Setup Environment
They should open a terminal in the project folder and run:

Bash
python3 -m venv venv
source venv/bin/activate  # On Windows: .\venv\Scripts\activate
pip install -r requirements.txt
Step 2: Check for Model Files
Tell them they must ensure the following files exist in the backend/symptom_ml/ folder, or the AI features will crash:

model.bin (The trained BERT weights)

id2label.json (The label mappings)

Note: If they don't have these files, they need to run the training script first:
python3 symptom_ml/train_kaggle.py

Step 3: Run the Servers
Backend:

Bash
cd backend && uvicorn main:app --reload --port 8000
Frontend:

Bash
cd frontend && python3 -m http.server 5500
3. Important: Handling the GPU
If the person you send this to has an NVIDIA GPU, they should install the CUDA-optimized version of Torch for better performance. Instead of the standard pip install, they should use:

Bash
pip install torch --index-url https://download.pytorch.org/whl/cu121
💡 What's being shared?
Code: All your .py and .html files.

Data: The data/Diseases_Symptoms.csv file.

Model: The model.bin (this is the most important for the AI to work immediately).
